# 雪山對戰美術 · v10.1.0

HTTP(S) 下預設採用新版雪山擂台、六角 3D 衍生圖與招式。加 `?art=classic` 切回舊版；加 `?art=3d` 則預選波洛／璃璃以延續私人試玩連結。首次開局約兩秒固定末幀運鏡，可按「跳過開場」或 Esc；減少動態效果、省電模式、`?intro=0` 不載影片。

- 兩套配色各有待機、施放、受擊、防禦、倒地；選角、必殺特寫、結算使用同一套模型導出的肖像。波洛收順臉頰輪廓，淡腮紅貼在面部。設定、介面圖示與通用粒子仍是原本的 2D。
- 19 款預渲染招式；攻擊路徑依角色站位，落空不播命中特效。水晶聖盾、水母城、防禦金鐘各有前、後兩層；兩種水母盾共用既有招式分類，不改技能數值。
- 波洛火球沿用已審過的 4 種出手／命中／盾吸收音效；璃璃兩種護盾和通用防禦亦有原創音效。其他招式保留原合成音。播放器沿用靜音及音量設定。
- 960×564 舞臺仍是離線 Blender 渲染，沒有 WebGL，也沒有手機端的 3D 面數。選角用縮圖包；戰鬥只取參戰角色的圖包和相關特效，背景或必要圖像載入失敗時使用舊版。
- 雪山含使用者提供的 3DGarden 冰拱、松樹、火炬和冰刺（ice-arch-02、snow-pine-01、torch-01、ice-spike-07），依 [3DGarden Licence](https://www.3dgarden.app/licence) 使用。網站不分發這四個來源 GLB，只有離線出圖。

本機在根目錄執行 `python3 -m http.server 8000`，開啟 `http://127.0.0.1:8000/`。直接用 `file://` 開會使用舊版，以免瀏覽器拒絕讀取圖包。開發者可用 `scripts/pack-rendered-art.py` 從原始渲染的 WebP 重新打包；公開檔內沒有模型母版。

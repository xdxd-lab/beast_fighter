# 萌獸鬥技場：下一批場景概念

v10.2.0 以本規格實作三場原創 Blender 擂台。只發布預渲染底圖和影片，來源場景不隨遊戲下載。當時的雪山試作為基準：960×564 靜態 WebP、2.0 秒相同末幀的 WebM/MP4、角色與招式由網頁分層合成，不動對戰規則。v10.4.0 的原生高解析度底圖、開場影片與預算見[四座擂台美術升級](ARENA-ART-REFRESH.md)。

## 共用鏡頭與戰鬥可讀性

- 三場景沿用同一個正面略俯視固定戰鬥鏡頭與角色接地線。A、B 分居畫面左／右，標記各用不同線型（A 單線、B 雙線）和文字，不用色相辨識玩家。地板記號不可搶過角色輪廓。背景保留角色站位的低細節對比區；中央打擊走廊不能被佈景打斷。
- 鏡頭只在首次開局的空場前導移動，可跳過；省電／減少動態效果直接顯示靜態底圖。約兩秒內完成，最後約四分之一秒停在正式鏡頭。輸出同一光照與構圖的最後一幀做擂台底圖，不在切換時改變亮度或裁切。
- Blender 分為遠景、擂台及左右佈景、可選透明前景。遊戲順序保留遠景＋地台 → 角色陰影 → 護盾後層 → 角色 → 護盾前層／可讀的投射物 → UI。真正前景只佔四角或地板前緣，既不越過角色／招式，也不碰血條、名字或傷害數字。最先用手機窄比例測試；若遮擋，不新增手機專用鏡頭，先減少或隱藏選配前景。
- 對照雪山約 52 KB 底圖、282 KB WebM（349 KB MP4），把新場景定為每場底圖與前景合計 ≤100 KB、首選影片 ≤350 KB 的目標。影片按場景懶載入，不建立每場備份的角色與特效。對照靜態、跳過、影片失敗四種進場，以及大身形＋透明角色與 A/B 同角色組合。
- 光和動態只屬場景，不把火焰、霧、浪或閃電建成有碰撞的技能。場景環境音待核心技能聲通過後再加，做低音量且可靜音，優先自行合成，不引入來源不清的長音樂。

## 1. 潮汐玻璃港（水下感，地面戰鬥）

- **畫面。** 以午夜藍、黯青海水與墨灰色堤岸做基底，擂台是乾燥、架高的石作港道，後方是斷桅與遠處玻璃般暗影。不是把雪山改藍：用水平碼頭和偏置船骸取代中央冰拱與圓盤輪廓。小片珊瑚是偏暖的唯一花色。
- **戰鬥鏡頭／A-B。** A 站位後設暗靛面，B 站位後設暖灰板；對戰姿勢仍左右朝中。暗色歐洛身後留一層極淡暖光，透明璃璃／水晶聖盾身後避免大片青白光斑。兩邊用相同亮度分布做可交換測試，不能只為指定角色布光。
- **前導／前景。** 從前左港燈外掠入，帶出船殼深度和低處泡沫；沿短弧歸位，不進入水中。角落礁碎、前緣濕石可分透明前景；泡沫、海草擺動和光束只留在影片或低對比遠景。無須把薄霧覆在璃璃身上。
- **素材。** Blender 自製墨石地面、斷桅、光束、泡沫和基本海草；若輪廓不夠，僅補一件有明確授權的低多邊形斷船或珊瑚群，可從已審核的 3DGarden 一件擇一，不用採購整包。首選測試璃璃／歐洛對位，再用波洛火球確認不會把背景亮點誤認為技能。

## 2. 月下竹影戲臺（江南木戲臺）

- **畫面。** 霧竹在後、織竹帷幕在中、帶細銅條的棋格式深色木舞臺在前；頂部只留一片低飽和靛藍夜色。外輪廓橫向如戲臺，暖琥珀與暗橄欖綠取代雪山的全冷色。兩側低燈籠與舞臺中央有明確窄暗縫區別。
- **戰鬥鏡頭／A-B。** 後幕用消光深青，竹枝不從角色頭頂穿過；地板比 A/B 服裝低飽和。高機動糰糰／啾槌的殘影和位移羽片不得和高頻竹葉疊色；背景欄杆不上到角色核心高度。
- **前導／前景。** 從一片偏斜的竹帷旁滑過，讓戲臺柱與遠林有視差；入場固定後，前景只剩底部矮竹和兩角木雕護欄，竹帷移除。暫不加滿場落葉，以免和攻擊粒子混淆。
- **素材。** 自製重複竹節、木板、紙燈籠與窗格。若耗時過高，只補 CC0 或已審核的竹叢／紙燈籠模型；不拷貝動畫 IP、品牌紋樣或現成受版權限制的樂曲。先測雙重裝角色在暖色地板是否站得住。

## 3. 雲階雷鼓台（山巔浮島）

- **畫面。** 遠端孤峰和剪影式浮島形成大空隙；擂台是短軸橢圓、霧黑玄武岩，以細黃銅條鋪平，後方使用兩面巨鼓的高低組合，不放中央門拱。背景主色是柔和淡紫灰，局部夕照，不能和亮黃攻擊撞色。
- **戰鬥鏡頭／A-B。** 平坦前台保留橫向打擊線；雷鼓置於遠側，鼓面亮紋不上升至角色肩線。A/B 站位用暗金單／雙線，兩角分別保留坦波大身形與啾槌空中動作。靜態背景不在戰鬥中閃電或全屏變亮。
- **前導／前景。** 由前緣上方小幅升起，露出岩下的雲層，再穩到共同鏡頭；可有一次安靜遠方雲光，不使用硬閃。前景只保留底部兩角的斷繩和略薄的碎岩，漂浮動態限於底線以下或遠景。
- **素材。** 自製鼓架、木皮、稜岩、平面霧與遠景過場；至多補一件無品牌、可合法再散布的鼓／山岩。若做環境音，先以原創低頻風聲與稀疏遠雷作試音，再驗證不掩蓋防禦命中提示。

## 建議順序與素材門檻

先做 **潮汐玻璃港**。與雪山差異最大，而且最早能暴露透明角色、護盾與前景遮擋問題。第二場用竹影戲臺測暖色與快速動作；第三場再做垂直層次與大身形驗證。每場先用現有或自製幾何灰模證明輪廓與裁切，再決定是否真的缺某一件素材。

目前使用者提供的冰拱、雪松、火炬、冰刺保留在雪山。新第三方素材在採用前記下原作者、資產網址、下載版本、授權與必要標註；尤其確認公開 GitHub / Pages 可包含何種成品或原始檔。原始授權與專案授權分開，不把外部音檔或模型直接標成專案授權。
